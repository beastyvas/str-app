# Cameo prompts (copy / paste)

For Gemini (Nano Banana) or any image model. For each character:

1. Paste the **Portrait** prompt and save the result as `<id>.png`.
2. Attach that portrait image, paste the **Hype edit** prompt and save the result as `<id>-hype.png`.
3. Drop both files in `assets/cameos/_inbox/` and run `node scripts/process-cameos.mjs`.

If the model refuses a named character, use the **No-name** version, which describes the look instead.

Your art goes into a personal TestFlight app only. Don't publish it anywhere public.
